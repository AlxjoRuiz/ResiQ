Las pruebas SQL de esta etapa cubren acceso legítimo, lectura ajena por ID y acciones cruzadas en los módulos indicados. No sustituyen pruebas de navegador de todas las rutas ni un entorno separado de producción. La prueba HTTP local suma 5 casos PASS (rutas de página, callback y seis endpoints de documentos), ejecutados con credenciales ficticias de Supabase. Solo acredita el comportamiento sin sesión; no acredita inicio de sesión real ni autorización entre roles. Para repetirla, iniciar Next localmente con `NEXT_PUBLIC_SUPABASE_URL=https://example.supabase.co` y `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY=sb_publishable_stage17_test`, definir `RESIQ_TEST_BASE_URL` con la URL local y ejecutar `node --test tests/e2e/unauthenticated-routes.test.mjs`.
